# WIDGETS.md — контракт виджетов

## Что нужно в index.html
Ровно пустые точки монтирования внутри `.widget-zone` соответствующих слайдов:
- слайд 5 (data-slide="4"): `<div data-widget="tools"></div>`
- слайд 6 (data-slide="5"): `<div data-widget="sandbox"></div>`
- слайд 9 (data-slide="8"): `<div data-widget="pulse"></div>`

Больше ничего: панель спикера (`.w-presenter`), лазерная указка (`.w-laser`),
кнопки реакций (`.w-reactions`) и частицы создаются `js/widgets.js` сами.

## Зависимости от deck.js
- `window.VibeDeck.state.index/total`, `prev()`, `next()` — используются защищённо.
- События `deck:ready` и `deck:change` (detail `{index, total, dir}`) — при входе
  на слайд с виджетом переигрывается staggered-вход (`.w-enter` → `.w-in`),
  состояние виджетов (режим sandbox, фильтр tools, голоса pulse) сохраняется.
- Заметки спикера: `data-notes` у `.slide.is-active`, обновление на `deck:change`.

## Использованные CSS-переменные (все с fallback)
`--accent, --on-accent, --card-bg, --card-border, --card-hover, --bg-elev,
--text, --text-2, --text-3, --success, --danger, --radius-md, --radius-sm,
--radius-card, --ease-out, --ease-spring, --dur-1, --dur-2, --dur-3,
--font-body, --font-mono, --shadow-2, --z-top`

## Поведение для QA
1. **sandbox (слайд 6)**: переключатель «Сделай красиво / Промпт с контекстом» →
   слева меняется промпт (кривая фраза ↔ структура Функциональность/Дизайн/Ограничения),
   справа морфится превью (съехавшие блоки ↔ аккуратная афиша), метрики:
   25%↔90% (анимированный счётчик), 10+↔3 итераций, Высокая↔Минимальная доводка.
2. **tools (слайд 5)**: чипы-фильтры («Все», «Просто начать», «Работа в редакторе»,
   «Свобода моделей», «Не только код») скрывают несовпадающие карточки; клик по
   карточке раскрывает деталь (аккордеон, aria-expanded); ползунок «Скорость ↔
   Контроль» подсвечивает лучший инструмент (акцентная рамка + бейдж «Подходит»).
3. **pulse (слайд 9)**: два вопроса (табы). Голос: клик по варианту — бар растёт
   (spring), процент и голоса пересчитываются; один голос на вопрос, повторный
   клик снимает. Q2 после голоса: верный — зелёная галочка, выбранный неверный —
   красный крестик. Голоса в localStorage `vibe-pulse-votes`; кнопка
   «Сбросить мои голоса». Стартовые демо-голоса Q1 [12,9,6,3], Q2 [5,8,3,2].
4. **presenter**: клавиша S (или Esc) — панель справа: заметки текущего слайда,
   таймер MM:SS (Старт/Пауза, Сброс), кнопки ← →, подсказки клавиш. На мобиле
   панель снизу. Клавиша L (удерживать, desktop) — лазерная точка за курсором.
   Кнопки реакций справа-снизу (сердце/искра/ладони) — фонтан частиц.
